# Pupputer Examples Directory

This directory contains 5 enriched example datasets used by both the preview pipeline (`scripts/build-preview.js`) and tests. Each scenario exercises distinct aspects of the rendering pipeline.

## Scenario Overview

| File | Scenario | Key Testing Focus |
| ---- | -------- | ----------------- |
| `basic.json` | Minimal starter tags | Verifies basic tag rendering without optional fields (no author, no date, no custom tags). |
| `with-metadata.json` | Tags with metadata | Tests full metadata parsing: author attribution, human-readable ISO date formatting (`formatDateLong`), and badge arrays. |
| `multi-lang.json` | Multilingual tags | Exercises UTF-8 encoding, non-ASCII characters (Indonesian, French, Spanish, Japanese), and slugification normalization (`slugify`). |
| `long-content.json` | Extended descriptions | Tests the ellipsis truncation algorithm (`truncate`) under fixed character budgets. |
| `themed.json` | Themed presets | Tests dynamic theme switching (`_theme` property) across `default`, `dark`, and `sepia` color themes. |

---

## 1. `basic.json`
Three minimal tags testing default values and graceful handling of absent properties:
- **Default options**: No explicit author, date, or tags.
- **Slug fallback**: Demonstrates automatic fallback to `slugify(name)`.
- **Expected result**: Clean title, description, and index navigation link.

## 2. `with-metadata.json`
Rich tag definitions testing full metadata integration:
- `slug`: Explicitly defined slugs (e.g., `release-1-0`).
- `author`: Attribution line displayed in `<header>`.
- `date`: Valid ISO `YYYY-MM-DD` converted into formatted date strings (e.g., `15 March 2025`).
- `tags`: Array of taxonomy labels rendered into badge chips in the `<footer>`.

## 3. `multi-lang.json`
Internationalization and Unicode resilience:
- Includes accented characters (Latin accents, diacritics) and CJK characters (Japanese: `こんにちは世界`).
- Tests that `escapeHtml` and `slugify` cleanly normalize unicode diacritics while preserving readable HTML representation.

## 4. `long-content.json`
Stress-testing text budgeting and truncation:
- Contains long paragraphs describing pipeline internals and migration guides.
- Truncates descriptions when `maxLength` is specified in render options, appending the `…` ellipsis safely within character limits.

## 5. `themed.json`
Custom theme configuration per tag:
- Includes `_theme` metadata read by `scripts/build-preview.js`.
- Renders individual pages with distinct stylesheets generated by `src/template/style.js`:
  - `default`: High-contrast light palette (`#ffffff`, `#222222`).
  - `dark`: Low-strain dark palette (`#1a1a1a`, `#e8e8e8`).
  - `sepia`: Warm editorial reading palette (`#f4ecd8`, `#3a2f22`).
